# 概述

## 1. 角色

修仙世界中, 每个角色都有自己的属性, 属性项可参考如下

- 资质: 决定了修炼的速度, 可通过丹药/突破境界提升一定天资

- 悟性: 决定了领悟功法以及术法的速度

- 大道领悟: 不同大道的领悟程度都能为修士提供增益, 大道分为: 金木水火土, 神, 剑, 体, 气, 阵, 丹, 器

- 灵根, 分为金木水火土五个基础灵根, 单一灵根占比越高, 修该属性的功法和术法的收益也就越高

- 可有1门主修功法, 5门辅修功法, 主修功法可带来50%的修为收益, 辅修功法则分别带来10%的修为收益, 如果辅修功法未满5门, 则按照剩下的50%比例分配, 若未有主修功法, 则100%收益来自辅修功法, 按比例分配

- 举例说明: 若只有主修功法1, 层级为1, 每日修为反馈为100, 闭关修行时, 每日反馈100修为; 若突破功法至层级2, 每日修为反馈200, 那么闭关修行时, 每日反馈200修为; 若不在闭关时, 例如在外探索, 也能有修为反馈, 但是能获得的修为非常低

- 修士的修为来源主要为两个: 功法以及资质, 闭关时, 资质也能带来修为收益; 除此之外, 服用丹药, 使用法宝, 战斗领悟等, 也能获取修为

## 2. 物品

- 草药/材料/符箓/炼丹炉/炼器炉 按照等级分为12个等级, 例如: 1级草药, 2级草药...(其他物品同理)

- 12个等级对应不同的品质与颜色, 最高等级颜色为红色, 最低为银白色, 中间等级的颜色你可以自由发挥设计

  > 小世界最多只有5级物品, 大世界最高有7级物品, 仙界最高有10级物品, 到了上层位面才有最高12级的物品

### 2.1 草药

- 做主药: 活血, 生息, 净血, 聚元, 炼魔, 驱妖, 诱妖, 御气, 振气

- 做辅药: 道蕴, 定煞, 锻体, 固元, 混元, 剑意, 解毒, 聚灵, 开窍, 开悟, 炼气, 凝神, 凝液, 培元, 强金, 强土, 强水, 强火, 强木, 清心, 神行, 调和, 洗髓, 养魂, 养气, 益寿, 凝婴, 化神, 避劫, 易容

- 药引: 性平, 性寒, 性热

### 2.2 材料

- 属性: 金木水火土, 神念, 剑, 混元

- 种类: 皮/鳞片, 牙/骨, 灵物, 金属, 石

- 阴阳: 天阳, 地阴

## 3. 功法

### 3.1 功法

修士的修炼功法, 为修士带来不同增益效果, 分为主修功法与辅修功法

- 不同功法对修士本身的资质以及天赋都有要求

- 不同资质与天赋的修士修同一功法也有不同的效果

- 功法属性: 金木水火土, 气, 神, 剑, 体, 遁术

- 不同等级功法有不同的修炼要求, 功法有12个等级, 1级功法最多修炼到1层, 2级功法最多修炼到2层, 以此类推; 修炼到不同层级会给修士带来不同的增益以及修为反馈

### 3.2 术法

- 修士之间攻伐的技能, 当然也有非杀伐类的术法, 例如治疗术, 召唤术之类

- 释放术法时, 主要消耗灵气, 可修多个术法

- 分为金木水火土, 剑, 神, 气, 阵法, 隐匿等属性

- 不同术法也有不同的领悟条件, 不同等级的术法释放时消耗的灵气也不同, 随着修士境界的提升, 术法的效果也会相应提升

## 4. 炼丹/炼器/炼符

### 4.1 炼丹/炼器

**炼丹**, 对应炼丹师

- 有疗伤丹药, 战斗丹药, 突破丹药

- 炼丹需炼丹炉

**炼器**, 对应炼器师

- 防具, 武器, 法宝, 配饰等

- 炼器续炼器炉

### 4.2 炼符

- 对应炼符师, 因为炼符的方法相当晦涩, 对修士的悟性有较高的要求

- 炼符需要符纸, 符纸主要使用树木制作, 修士使用灵力在符纸上刻画灵纹而成

## 5. 宗门

门派为修士提供修行场所, 弟子也需要为维持宗门正常运转而参与到种植灵田, 炼丹, 炼气, 战斗等工作中

### 5.1 宗门职位

门派中不同职位的修士有不同的职责, 不同门派的职位划分都有所不同, 但大体上都差不多, 一般的门派职位划分如下

- `太上长老`, 门派中, 当代资历最老的修士, 一般来讲也对应战力最强的修士, 大多数时候都在门派秘境中闭关寻求突破, 若非门派遭遇灭门危机, 不会轻易露面出手

- `掌门`, 门派掌权者, 明面上的最高话事人, 负责门派大大小小的管理, 包括长老的任命, 门规的指定以及修改等

- `长老`, 负责门派中不同职能部门的管理以及运营, 门派的关键战力; 根据不同部门, 可分为`炼丹堂长老`, `炼器堂长老`, `执法堂长老`, `外务长老`, `挂名长老`, `客卿长老`等, 各长老直接向掌门汇报

### 5.2 宗门类别

不同门派所修功法均有所不同, 可根据其对不同门派进行分类

## 6. 种族

- 不同角色有不同种族, 种族可分不同亚种

- 不同种族有各自的特性与修炼天赋
