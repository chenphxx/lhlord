# 剧情大纲

> 说明: 本文档给出游戏主线剧情的整体框架与阶段目标, 供后续任务, 关卡与角色设定展开; 世界观规则以 [概述](概述.md) 与 [境界](境界.md) 为准
> 状态: 大纲草案, 章节, 任务与对白待细化
> 关联文档: [概述](概述.md), [境界](境界.md), [炼丹](炼丹.md)

## 1. 主题与基调

> 天赋不够, 看得太远只会步步维艰

- 主题: 修行是向天地借力, 借得越多, 越要回答自己为何而修
- 前三卷回答能不能走得更远, 第四卷回答走得更远之后要做什么
- 基调: 小世界的山野求生, 大世界的万族博弈, 仙界的秩序与谎言, 上层位面的法则自省
- 主线角色为玩家创建的无名修士, 出身人族凡人, 起步于小世界青岚山; 剧情文本涉及该角色时统一称为你

## 2. 主线脉络

### 2.1 第一卷 青岚问道(小世界, 炼气 至 化神)

一句话: 你在青岚山醒来, 用一炉草药敲开仙门, 从小世界的边缘走进宗门的棋盘

- 开局: 身边只有几味草药与一尊旧丹炉, 靠辨识药性, 试炼回春丹换取第一笔灵石
- 入门: 丹霞谷弟子苏云裳将你引荐入青云宗外门, 你第一次知道丹方, 灵田与贡献值才是散修的活路
- 成长: 在青云宗, 丹霞谷, 玄铁门, 天机阁之间接取委托, 以种植灵田, 炼丹, 探索与守卫换取资源
- 冲突: 小世界灵气逐年稀薄, 四派为灵脉与丹方明争暗斗; 魔渊煞气外溢, 兽潮与魔裔探子趁虚而入
- 转折: 天机阁掌门陆沉舟推演出小世界天道有缺, 化神修士一旦全力出手, 必被天道排斥并强制飞升
- 高潮: 四派在魔渊裂口联手封堵煞气, 你于阵前突破化神, 也第一次听见天道之外的注视
- 收束: 为不牵连师门, 你主动引动飞升, 只带走一炉丹与陆沉舟的一句嘱托: 去看看天道为什么缺了一块
- 本卷玩法: 开局, 探索, 闭关, 突破, 炼丹, 灵田, 丹毒
- 本卷待扩展: 战斗, 功法, 术法与宗门任务

### 2.2 第二卷 万族逐道(大世界, 炼虚 至 渡劫)

一句话: 天道补全了, 但万族都在争夺补全之后的位置

- 飞升后: 你落在太虚山外围, 发现大世界并不排斥外来者, 排斥的是没有背景的外来者
- 阵营: 太虚剑派代表人族正统, 万妖盟代表妖族自强, 散修联盟在两强之间求生
- 妖族线: 万妖盟之主白灵已逾千岁, 她认同你从底层往上爬的路径, 也试探你是否愿意成为妖族的话语人
- 魔族线: 修罗剑修墨渊因不满太虚剑派的门第之见离门, 如今以杀戮之道行走大世界, 是镜子也是对手
- 龙凤线: 太虚剑派弟子敖烈身负青龙血脉, 却因龙族旧约受限; 火凤血脉的凤九歌掌丹霞谷, 其涅槃之能牵出一段被掩盖的旧史
- 冲突: 渡劫修士渡的不是雷, 是名额; 仙界对下界的接引并非无限, 大世界的顶点之争本质是飞升资格之争
- 高潮: 你以渡劫之身挑战太虚山旧例, 主张飞升名额不计出身
- 收束: 仙界降下接引, 玄清真人现身, 他认出了你身上的天道印记
- 本卷待扩展: 跨位面旅行, 声望与阵营, 妖族血脉, 渡劫战斗

### 2.3 第三卷 仙路问心(仙界, 人仙 至 圣仙)

一句话: 仙界秩序井然, 井然得不像人间

- 世界观反转: 仙界并非修行者的终点, 而是上层位面的苗圃; 仙气, 仙脉与丹材都按秩序被收割
- 引路人: 紫霄宫长老玄清真人, 仙裔出身, 两千年来第一次对仙界的秩序生出疑问
- 秩序: 紫霄宫以仙律约束诸仙, 违律者贬入下界; 你发现小世界天道残缺与仙界律令有关
- 炼丹线: 仙界的丹方与丹毒机制远比下界精巧, 你以丹入道, 逐步触及以丹改命的禁忌
- 冲突: 仙界以圣仙为锋, 镇压任何试图溯流而上的修士; 陆沉舟当年的推演被逐条证实
- 高潮: 你与玄清联手, 打开仙界与下层位面之间的封印, 让仙气重新流入下界
- 收束: 仙界震怒, 上层位面降下法旨, 你被请入混沌海
- 本卷待扩展: 仙律与身份, 高阶炼丹, 仙脉争夺

### 2.4 第四卷 混元证道(上层位面, 混沌仙 至 仙帝)

一句话: 到了法则的尽头, 你要选的是让谁来决定万界的形状

- 真相: 上古仙帝之战打碎了小世界天道, 胜者以收割万界灵气维系上层位面, 混沌圣殿便是旧秩序的守门人
- 对手: 混沌圣殿试图招揽你成为新的秩序执行者, 代价是亲手封回下界的通路
- 抉择: 你的道与旧秩序冲突, 是自上而下的秩序, 还是自下而上的生长
- 高潮: 与仙帝级一战的胜负不在战力, 而在道; 仙帝只有仙帝能与之为敌, 你要先成为仙帝
- 结局方向: 你打破收割循环, 把法则还给万界; 代价是上层位面失去永恒, 你也失去了凌驾众生的可能
- 收束: 青岚山的一场春雨落入灵田, 无名修士的故事回到起点, 成为后来者的传说

## 3. 势力与人物

### 3.1 势力

| 势力 | 位面 | 立场 | 剧情作用 |
| --- | --- | --- | --- |
| 青云宗 | 小世界 | 正道剑修 | 主角入门之地, 守正辟邪的标尺 |
| 丹霞谷 | 小世界 | 丹道济世 | 主角炼丹与谋生的起点, 掌门凤九歌为关键人物 |
| 玄铁门 | 小世界 | 器修名门 | 提供炼器, 法宝与门派委托 |
| 天机阁 | 小世界 | 隐世阵修 | 推演出天道有缺, 掌门陆沉舟是主线的引子 |
| 太虚剑派 | 大世界 | 人族正统剑道 | 大世界秩序的代表, 与墨渊, 敖烈同源不同命 |
| 万妖盟 | 大世界 | 妖族联盟 | 万族视角的入口, 盟主为白灵 |
| 紫霄宫 | 仙界 | 仙界秩序 | 仙界规则的执行者, 玄清真人的疑问是反转起点 |
| 混沌圣殿 | 上层位面 | 旧秩序守门人 | 终局对手, 收割循环的维护者 |

### 3.2 主要人物

- 陆沉舟: 天机阁掌门, 隐族阵修, 善推演天机; 主角踏出小世界的原因
- 凤九歌: 丹霞谷掌门, 火凤血脉, 三百岁, 涅槃重生之身; 旧史的见证者
- 白灵: 万妖盟之主, 万年狐妖, 神念通玄; 妖族线与万族视角的核心
- 墨渊: 修罗剑修, 大世界散修, 曾入太虚剑派后离门; 主角的镜子与对手
- 敖烈: 太虚剑派弟子, 青龙血脉, 剑道天赋卓绝; 龙族旧约的束缚者
- 玄清: 紫霄宫长老, 仙裔气修, 两千岁; 仙界的怀疑者与同盟
- 苏云裳, 林清玄, 铁如山, 火灵儿, 阿蛮, 云中鹤: 各卷的师友, 同门与引路人, 承担支线与门派委托

## 4. 主要支线

- 丹道线: 从回春丹到高阶突破丹, 以试药, 识药, 改方推进; 对应炼丹系统的探索感与优化空间
- 丹毒线: 为求速成滥用突破丹, 丹毒缠身, 需以净血丹药, 洗髓辅药与时间偿还; 对应丹毒与耐药机制
- 灵田线: 种药, 炼丹, 药渣养田的循环, 是散修最朴素的立足方式
- 门派线: 贡献值, 职务与值守任务, 展现门派不只是靠山也是枷锁
- 血脉线: 龙族旧约, 凤族涅槃, 灵族化形, 鬼族残魂, 对应不同种族的修炼特性
- 魔渊线: 煞气, 魔裔与修罗, 追问魔族嗜杀是本性还是被写好的命运
- 遗迹线: 上古战场遗物与残缺丹方, 逐步拼出仙帝之战的真相

## 5. 伏笔与暗线

- 青岚山: 主角醒来的地方并非偶然, 它与上古仙帝之战的余波有关
- 天道有缺: 第一卷的结论, 第三卷的答案, 第四卷的起因
- 丹炉: 开局那尊旧丹炉来历不明, 是旧秩序留下的钥匙
- 强制飞升: 化神全力出手会被天道排斥, 这条规则本身就是被设计出来的
- 墨渊的离门: 太虚剑派的门第之见与仙界名额之争同源
- 凤九歌的涅槃: 涅槃重生并非无敌, 而是以记忆与寿元为代价
- 看得太远只会步步维艰: 既是陆沉舟的警告, 也是主角最终选择的注脚

## 7. 待确认事项

1. 主角是否保留固定姓名与固定出身, 还是完全由玩家自定义并只以你称呼
2. 主线是线性四卷, 还是允许玩家在小世界阶段长期停留, 以门派经营为主
3. 墨渊定位是反派, 亦敌亦友, 还是可招募的同伴
4. 结局是唯一结局, 还是按道心与阵营分支多结局
5. 剧情是否与后续战斗, 功法与宗门系统同步开发, 还是先以文字与任务形式落地
